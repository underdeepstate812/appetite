## 1. Что это и как запустить

Монорепо pnpm: `apps/backend` (NestJS + Prisma + Postgres/Redis), `apps/web` (Vite React, обычный CSS), `apps/admin`,
`apps/mobile` (Expo 57 / RN 0.86 / react-native-web 0.21, навигация React Navigation), `packages/shared`.
Пользователь говорит по-русски — **отвечать по-русски**. Пользователь просит: уникальный, не шаблонный дизайн; проверять
сделанное и показывать скриншоты; не коммитить без просьбы; тестовые пароли вводить только на localhost (демо-аккаунты из seed);
туннели — только по слову пользователя.

```bash
open -a Docker && docker compose up -d postgres redis      # после перезагрузки всё падает
pnpm --filter @apetite/backend dev                          # :3000
pnpm --filter @apetite/backend prisma:seed:showcase         # окна витрины живут по часам — обновлять каждое утро (иначе 3 оффера)
cd apps/mobile && npx expo start --web --port 8081         # mobile-web
pnpm --filter @apetite/web dev  # :5174 ;  pnpm --filter @apetite/admin dev  # :5173
```
Демо-вход: `user@apetite.ru` / `password123` (seed). Туннель для показа: см. раздел «Туннель» в `apps/mobile/README.md`
(два cloudflared + второй Expo с `EXPO_PUBLIC_API_BASE_URL`, без `CI=1`).

## 3. Дизайн-язык «Ember» (не нарушать без просьбы)

Подробно: память проекта `project_apetite_design_history`, `docs/ux/ux-audit-2026-10.md`, `apps/mobile/README.md`.
- **Жар = время**: цвет красит только остаток окна (мята → янтарь → ember → красный только в последние ~30 мин) через `theme/heat.ts`.
  Текст жара — только `heatInk` (≥4.5:1).
- Палитра/токены: `theme/tokens.ts` (мятный primary `#0F766E`/`#2DD4BF`, ember `#B5380A`/`#FF8A3D`, тёмная — бирюзово-чёрная `#0B1110`).
- **Фирменный контур 4/18/4/18 — только у кнопок** (`signatureRadius`). Отклонено: плашки/«тарелки», pill-кнопка с рамкой, пергамент.
- Шрифт: Unbounded только 700 (цифры, короткие заголовки), текст — системный.
- Стекло допустимо, но не перегружать (`theme/glass.ts`, `components/glass/*`, `kit/*`). Haptic-партитуры — `utils/haptics.ts`.
- Примитивы: `Button` (есть `pulse`), `DiscountStamp`, `FuseTimer`, `OfferThumb`, `PickupTicket`, `SparkBurst`, `StaggerReveal`, `Screen`.
- Движение: `Animated` с native driver, **Reanimated не установлен**; всегда путь для `useReducedMotion`.

## 5. Находки и рекомендации (по убыванию важности)

### Безопасность / зависимости (решение за владельцем)
1. **Backend, multer** (через `@nestjs/platform-express`): high/moderate, исправлено в `multer ≥ 2.4.0`. Через него идут загрузки фото
   (админка, аватар) — а API временами торчит в интернет через туннель. Рекомендация: `pnpm.overrides` на multer ≥ 2.4.0 и прогон `qa_admin_photo`, `qa_mobile_orders` (аватар).
2. **Backend, deepmerge-ts < 8** (high) — транзитивная, проверить, кто её тянет.
3. **Mobile, shell-quote (critical), node-forge, braces, source-map-js, uuid** — все транзитивные из dev-инструментов Expo/Metro; в
   сборку приложения не попадают. Обновляются вместе с версией Expo.
4. **web/admin: react-router < 7.18** (moderate) — обновить минорно.
Сам я зависимости не менял (меняют lockfile и поведение).

### Мобильный UI/UX — что не проверено и что стоит сделать
- **Нативная часть не проверена на устройстве**: `react-native-maps` (`NativeMapSurface`), `expo-splash-screen`, новые иконки/сплэш, haptic, `SecureStore`, бегущая лента на native driver, backdrop-blur (на native его нет — только полупрозрачность). Есть только типы, jest с моками и `expo export`. **Первым делом — прогон на реальном iPhone и Android** (и фиксация находок).
- **Гостевой режим не реализован**: до регистрации нельзя посмотреть ни одного оффера (в UX-аудите F4, sev 3). Welcome это смягчает «витриной в миниатюре», но не снимает.
- **Android**: не настроены `BackHandler`/predictive back (оставлено выключенным), нет Material-3-динамического цвета (осознанно — свой язык).
- **Dynamic Type / крупный шрифт**: не проверялся (карточки ленты и карты — фиксированная высота 84/112 px; при увеличенном шрифте обрежутся).
- **Планшет/десктоп**: Home растягивается (список в 2 колонки), Welcome ограничен 560 px; остальные экраны — на широком экране без отдельной раскладки.
- **Push**: токен регистрируется, реальная доставка не проверялась ни разу (`EXPO_PUSH_MODE=mock`); уведомления об отмене/просрочке заказа не отправляются (`docs/BACKLOG.md`).
- **Платёж** — mock-провайдер; для реального запуска нужен настоящий (`docs/BACKLOG.md`, «Перед показом реальным пользователям»).
- Лента «Сейчас» дублирует список ниже (список нужен для вкладок и фильтров) — обсудить, не лишний ли блок «Хот-скидки рядом».
- Старые компоненты ставят `accessibilityElementsHidden`/`importantForAccessibility` — **на web (RN-web) они не работают, нужен `aria-hidden`**: проп добавлен в новые компоненты (WelcomeArt, DayHeroArt, лента, Button-кольцо), в 17 старых файлах — нет. Не ломает axe сейчас, но для VoiceOver в Safari лишнее читается (список файлов: `grep -rl accessibilityElementsHidden apps/mobile/src`).
- Заглушки: у `FuseTimer` в каждой карточке свой JS-driver анимации длины (в списке из десятков карточек — лишняя работа); если появятся лаги на слабых телефонах — первое место для оптимизации (общий тик, как у `useBreath`).

### Гигиена репозитория
- ≈250 незакоммиченных файлов, ветка `feature/web-shop-map-oneclick`; крупные независимые куски (mobile redesign, web showcase, backend featured/offer photos) лучше коммитить раздельно.
- `img/` в коммиты не включать (договорённость).
- `corner_hover.png` в корне — артефакт, можно удалить.

## 6. Тестирование: как гонять и что в какой набор входит

Юнит: `pnpm -r test` (mobile — jest-expo + RNTL; web — vitest; backend — jest). Типы: `pnpm -r lint` (= tsc).
Браузерные (Playwright, python3; нужны поднятые серверы, подробности и порты — `qa/README.md`):

| Набор | Что проверяет |
|---|---|
| `qa_mobile.py` | все экраны на ЗАМОКАННОМ API (фикстуры, без паролей) |
| `qa_mobile_auth.py` | вход/регистрация, небо по часам, постер-«лента», axe |
| `qa_mobile_welcome.py` | заставка, Welcome (карта, пульсирующие кнопки), раскладка 320…768, axe |
| `qa_mobile_map.py` | вкладка «Карта»: лента карточек, синхрон пин↔карточка, список, геопозиция |
| `qa_mobile_ribbon.py` | бегущая лента на «Сейчас»: движение, пауза, нажатие, a11y |
| `qa_mobile_offer/orders/food/lab.py` | экран оффера, заказы/билет/офлайн, состав и «получил ли заказ», `/ui-lab` |
| `qa_mobile_real.py` | сквозной сценарий на РЕАЛЬНОМ backend (демо-аккаунт, оплата, QR) — только localhost |
| `qa_web*.py`, `qa_admin*.py`, `qa_api.py`, `qa_food_receipt_api.py`, `qa_a11y.py` | сайт, админка, API |

Ловушки QA (все найдены на практике):
- RN-web подменяет DOM-`scrollTo` у ScrollView на `{x, y}` → в Playwright звать `Element.prototype.scrollTo`.
- Pressable на web: `focusable={false}` игнорируется, нужен `tabIndex={-1}`; касание фокусирует кнопку ДО клика (не делать «выбор по onFocus» без `isKeyboardFocus`, `utils/focus.ts`).
- Playwright не кликает по движущемуся элементу («not stable»): для бегущей ленты вести указатель на карточку и жать вручную.
- Карточки ленты — `role=button` с «₽» в подписи: селекторы строк списка исключают `[data-testid=offer-ribbon]`.
- `page.clock.set_fixed_time` замораживает RN Animated — для другого времени суток сдвигать `Date` init-скриптом (`shift_clock` в `qa_mobile_auth.py`).
- RNTL: aria-hidden элементы по умолчанию невидимы для запросов (`includeHiddenElements: true`); у `AccessibilityInfo` в jest «мок-функция» — `restoreAllMocks` её не откатывает, использовать `mockResolvedValueOnce`.
- Тесты с окнами «−1 ч…+2,5 ч» не должны зависеть от часа запуска.
- Витрина seed стареет за ночь — `prisma:seed:showcase` перед QA на реальном backend.
- `CI=1 expo start` отключает слежение за файлами (для туннеля с живыми правками — без CI).
