Исходники фоновой картинки бренда (SVG, 1080×1620). JPEG в `../` получены рендером в Chromium (Playwright:
`page.set_content(<svg>)` → `screenshot(type="jpeg", quality=82)`). Правите SVG — перерисуйте JPEG тем же способом.
- `hero-ember.svg` → `hero-ember.jpg`: «солнце» со срезами и кольцами (экраны входа/регистрации).
- `hero-ember-quiet.svg` → `hero-ember-quiet.jpg`: без диска, только свечение и кольца (пропуск профиля: поверх длинный текст).
